What a user has to do today, and why it's hard

  • 1Nothing in the top bar says you are needed. The Escalations link and its badge sit inside the account menu, and the bell mixes an agent's question in with “commented on” lines, with no filter. Live (23 to 25 unread, nearly all comments)
  • 2The pending count leaves things out. It counts only agent questions, not redesign proposals or project-rule approvals. Code
  • 3A blocked agent can look like it's working. The status rule counts only questions, so an agent stuck on a project-rule approval still reads “Working”. Code Assumption: how often this happens
  • 4“Waiting on you” isn't actionable. No link and no preview of the question on the dashboard row; you go to Escalations by hand. Code
  • 5A stopped agent shows “Offline”, with no reason. Ziki records why a claim was released (silence, a missed deadline, or waiting too long on the owner), but the dashboard doesn't show it, and I found no notification telling the owner. Code
  • 6A finished agent looks like an idle one. “Standing by” says nothing about what it delivered. Finished work is only visible in the audit log, which is empty for my own agent on the live site (cause unknown). Code Live
  • 7You can't see how long you have. One reminder after 30 min; after a default 4-hour wait the agent releases the issue. Code
